# Customer Call List Data Cleaning and Preparation with Python & Pandas

## Overview

Data cleaning is one of the most important stages of any data analytics project. In this project, I worked with a customer call list dataset containing various data quality issues such as duplicate records, inconsistent formatting, missing values, unnecessary columns, and improperly structured information.

Using Python and Pandas, I cleaned and transformed the dataset into a structured, accurate, and analysis-ready format.

---

## Project Objectives

The main objectives of this project were to:

- Identify and remove duplicate records.
- Handle missing and null values.
- Standardize text and categorical data.
- Clean phone number formats.
- Remove unnecessary columns.
- Split address information into separate fields.
- Improve overall data quality and consistency.
- Prepare the dataset for future analysis and reporting.

---

## Dataset Overview

The dataset contains customer information including:

- Customer ID
- First Name
- Last Name
- Phone Number
- Address
- Paying Customer Status
- Contact Preferences

The raw dataset contained several inconsistencies that required cleaning before meaningful analysis could be performed.

## Data Cleaning Process

### 1. Duplicate Removal

- Identified duplicate customer records.
- Removed duplicate entries to improve data accuracy.

### 2. Missing Value Handling

- Replaced null and missing values where necessary.
- Standardized blank entries for consistency.

### 3. Phone Number Standardization

- Removed special characters and inconsistent formatting.
- Converted phone numbers into a uniform structure.

### 4. Text Cleaning

- Removed unwanted characters.
- Standardized text values across multiple columns.
- Corrected inconsistent entries.

### 5. Address Transformation

- Split address information into separate fields.
- Extracted street addresses and location details for better usability.

### 6. Column Cleanup

- Removed irrelevant and unnecessary columns.
- Retained only fields useful for future analysis.

### 7. Record Filtering

- Removed records that should not be contacted.
- Eliminated invalid or incomplete customer information.
